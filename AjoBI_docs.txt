<h1><a id="_c09wkck6ucv6"></a><strong>AjoBI — Full Development Documentation</strong></h1><h2><a id="_4mtqja31sbtr"></a><strong>Overview</strong></h2><p>AjoBI has four core features: Auth &amp; AjoScore, Digital Ajo Groups, Savings Goals, and Simple Escrow. The backend is PHP (REST API), the frontend is React. Each developer owns a vertical — one person can work on Ajo Groups while another works on Savings Goals without touching the same files or endpoints.</p><h2><a id="_ufordrnz0obg"></a><strong>How the Codebase is Structured</strong></h2><p><strong>Frontend (React)</strong></p><p>src/</p><p>  pages/</p><p>    auth/</p><p>    dashboard/</p><p>    groups/</p><p>    savings/</p><p>    escrow/</p><p>    admin/</p><p>  components/</p><p>  hooks/</p><p>  services/       ← all API calls live here</p><p>  context/</p><p><strong>Backend (PHP)</strong></p><p>api/</p><p>  auth/</p><p>  ajoscore/</p><p>  groups/</p><p>  savings/</p><p>  escrow/</p><p>  admin/</p><p>  webhooks/</p><p>config/</p><p>middleware/</p><p>models/</p><p>Each feature folder is self-contained. Two developers never edit the same file at the same time if they own different features.</p><h2><a id="_coookcuhvj0v"></a><strong>Feature 1 — Auth &amp; AjoScore</strong></h2><h3><a id="_9dhf2cjpayxv"></a><strong>What it does</strong></h3><p>User signs up, completes onboarding, gets a base AjoScore. Everyone authorizes Paystack Direct Debit. Every cycle the platform auto-charges all members and auto-disburses the pot to whoever is next in rotation.</p><h3><a id="_tc2jb1pscqom"></a><strong>Frontend pages</strong></h3><ul><li>/groups — list of groups user belongs to</li><li>/groups/create — form to create a new group</li><li>/groups/join/:code — join via invite code</li><li>/groups/:id — group dashboard: members, payment status, rotation order, next payout</li><li>/groups/:id/setup-debit — Paystack Direct Debit authorization page</li></ul><h3><a id="_y7ca8bfum6b5"></a><strong>Frontend API calls</strong></h3><p>POST /api/groups/create</p><p>POST /api/groups/join</p><p>GET  /api/groups/mine</p><p>GET  /api/groups/:id</p><p>GET  /api/groups/:id/members</p><p>GET  /api/groups/:id/payments</p><p>POST /api/groups/:id/setup-debit   ← initiates Paystack auth</p><h3><a id="_3yu76wu7lre5"></a><strong>Backend endpoints</strong></h3><p>POST /api/groups/create</p><p>  - Checks group is not full</p><p>  - Adds user as member</p><p>  - Assigns rotation position</p><p>  - Returns group details</p><p>GET /api/groups/:id</p><p>  - Returns group info, member list,</p><p>    current cycle, rotation order,</p><p>    who has paid, who receives next payout</p><p>POST /api/groups/:id/setup-debit</p><p>  - Calls Paystack to initialize mandate</p><p>  - Returns authorization URL</p><p>  - Frontend redirects user to Paystack page</p><p>  - After auth, Paystack redirects back with mandate code</p><p>  - Backend saves mandate code against member record</p><p>[CRON JOB — runs on due date]</p><p>  - For each active group where today = collection date:</p><p>    - Loop through all members</p><p>    - Call Paystack Charge Authorization on each mandate</p><p>    - Mark payment as pending</p><p>[WEBHOOK — charge.success]</p><p>  - Find the group and member from metadata</p><p>  - Mark member as paid for this cycle</p><p>  - If ALL members paid:</p><p>    → Find next recipient in rotation</p><p>    → Call Paystack Transfer to their account</p><p>    → Mark cycle as complete</p><p>    → Update everyone's AjoScore (+2)</p><p>    → Move rotation to next person</p><p>    → Set next cycle date</p><p>[WEBHOOK — charge.failed]</p><p>  - Platform calculates the instalment, auto-debits on schedule via Paystack, and locks the funds until the goal date.</p><h3><a id="_hrgtcf1wluqu"></a><strong>Frontend pages</strong></h3><ul><li>/savings — list of user's active goals with progress bars</li><li>/savings/create — form: goal name, target amount, deadline, frequency</li><li>/savings/:id — goal detail: amount saved, next debit, projected completion, break option</li></ul><h3><a id="_9tzyjkihebom"></a><strong>Frontend API calls</strong></h3><p>POST /api/savings/create</p><p>GET  /api/savings/mine</p><p>GET  /api/savings/:id</p><p>POST /api/savings/:id/break   ← early withdrawal</p><p>POST /api/savings/:id/setup-debit</p><h3><a id="_4zngr4o0k47u"></a><strong>Backend endpoints</strong></h3><p>POST /api/savings/create</p><p>  - Receives goal name, target, deadline, frequency</p><p>  - Calculates instalment = target ÷ number of periods</p><p>  - Creates goal record with status "pending_debit_setup"</p><p>  - Returns instalment breakdown</p><p>POST /api/savings/:id/setup-debit</p><p>  - Receives amount, description, optional recipient info</p><p>  - Creates escrow record with status "awaiting_payment"</p><p>  - Calls Paystack Payment Page API to generate payment link</p><p>  - Returns link: pay.ajobi.app/esc_xyz123</p><p>GET /api/escrow/public/:code</p><p>  - No auth required</p><p>  - Returns escrow amount, description, status</p><p>  - Frontend shows pay button or status message</p><p>[WEBHOOK — charge.success from escrow payment link]</p><p>  - Matches payment to escrow record via metadata</p><p>  -
