AjoBI — API Contract Document
For Frontend & Backend Teams to Work Independently
How to Use This Document
Backend team:
 Build endpoints to match these exact request and response shapes. Do not change field names.
Frontend team:
 Build UI and API calls against these exact shapes. Use the base URL once backend deploys. Until then use mock data that matches these exact response shapes.
Base URL:
 
https://ajobi-production.up.railway.app
Authentication:
 All endpoints except Register and Login require:
Headers:
  Authorization: Bearer <token>
  Content-Type: application/json
Standard Error Response (all endpoints):
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Token is invalid or expired"
  }
}
Standard Success Wrapper:
{
  "success": true,
  "data": { }
}
STAGE 1 — AUTHENTICATION
Register
POST /api/auth/register
Auth required: No
Request Body:
{
  "full_name": "Emeka Obi",
  "phone": "08012345678",
  "email": "emeka@email.com",
  "password": "secret123"
}
Validation Rules (Frontend shows these errors):
full_name   → required, min 2 characters
phone       → required, valid Nigerian number, unique
email       → optional, valid email format if provided
password    → required, min 6 characters
Success Response — 201:
{
  "success": true,
  "data": {
    "user_id": "usr_a1b2c3d4",
    "full_name": "Emeka Obi",
    "phone": "08012345678",
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "onboarding_complete": false
  }
}
Error Responses:
{ "error": { "code": "PHONE_EXISTS", 
             "message": "An account with this phone number already exists" } }
{ "error": { "code": "VALIDATION_ERROR", 
             "message": "Phone number is not valid" } }
Login
POST /api/auth/login
Auth required: No
Request Body:
{
  "phone": "08012345678",
  "password": "secret123"
}
Success Response — 200:
{
  "success": true,
  "data": {
    "user_id": "usr_a1b2c3d4",
    "full_name": "Emeka Obi",
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "ajo_score": 68,
    "score_tier": "Silver",
    "onboarding_complete": true
  }
}
Frontend Logic:
if onboarding_complete === false → redirect to /onboarding
if onboarding_complete === true  → redirect to /dashboard
Error Responses:
{ "error": { "code": "INVALID_CREDENTIALS", 
             "message": "Phone number or password is incorrect" } }
{ "error": { "code": "ACCOUNT_SUSPENDED", 
             "message": "Your account has been suspended" } }

STAGE 2 — ONBOARDING
Five steps. Each step submits independently so progress is saved if user drops off.
Submit Onboarding Step 1 — Who Are You
POST /api/onboarding/step1
Auth required: Yes
Request Body:
{
  "occupation": "Trader"
}
Occupation options (frontend renders these):
Trader / Market Seller
Artisan / Craftsperson
Service Provider
Job Seeker
Farmer
Other
Success Response — 200:
{
  "success": true,
  "data": {
    "step_completed": 1,
    "next_step": 2
  }
}
Submit Onboarding Step 2 — Your Work
POST /api/onboarding/step2
Auth required: Yes
Request Body:
{
  "trade_duration": "1-3 years",
  "state": "Lagos",
  "lga": "Surulere",
  "income_range": "20000-50000"
}
Field Options:
trade_duration:
  "less than 1 year"
  "1-3 years"
  "3-5 years"

  "below 5000"
  "5000-20000"
  "20000-50000"
  "50000-100000"

    "step_completed": 2,
